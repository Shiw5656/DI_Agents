
# Data Vault Glossary and Data Dictionary

## Executive Overview
This document provides a complete data dictionary and glossary for the International Baccalaureate (IB) School Data Vault model. The inventories below were generated by parsing the provided SQL Server DDL. The model includes hubs for core business entities like Student, Teacher, and Course, along with links and satellites to capture relationships and descriptive attributes.

A key limitation is the absence of data profiling results, as the provided file (`previous_agent_or_workflow_output.txt`) did not contain this information. As a result, business definitions are derived solely from DDL comments, and data quality metrics are not included.
